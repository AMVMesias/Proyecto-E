# Asignatura

**PROYECTOS DE INTELIGENCIA DE NEGOCIOS**

# Macroactividad: Construir un proyecto BI con datos, ETL, dashboard e informe ejecutivo

<!-- Página 1 -->

## 1. Caso real

Una empresa comercial presenta dificultades para controlar sus ventas, productos, clientes y metas mensuales. Actualmente, la información se encuentra dispersa en hojas de cálculo, reportes manuales y registros de ventas no integrados. Esta situación impide conocer con precisión qué productos generan mayor ingreso, qué vendedores cumplen sus metas, qué zonas tienen bajo rendimiento y qué decisiones deben tomarse para mejorar los resultados.

Frente a este problema, el estudiante deberá construir un proyecto de inteligencia de negocios que integre datos reales o simulados de ventas, clientes, productos, vendedores y metas comerciales. La solución deberá incluir limpieza de datos, flujo ETL, modelo de datos, dashboard interactivo e informe ejecutivo para la toma de decisiones.

## 2. Propósito de la macroactividad

La macroactividad tiene como propósito que el estudiante aplique el ciclo básico de un proyecto BI, desde la comprensión del problema de negocio hasta la presentación de hallazgos ejecutivos. El trabajo permitirá transformar datos dispersos en información clara, visual y útil para la toma de decisiones estratégicas, tácticas y operativas.

## 3. Problema a resolver

La empresa necesita responder las siguientes preguntas de gestión:

1. ¿Cuáles son los productos más vendidos y rentables?
2. ¿Qué vendedores cumplen o incumplen sus metas?
3. ¿Qué zonas o canales presentan mayor o menor desempeño?
4. ¿Cómo evolucionan las ventas por mes?
5. ¿Cuál es la predicción de ventas?
6. ¿Cuál es la segmentación de los clientes?
7. ¿Cuál es la segmentación de las series temporales? (Productos)

## 4. Producto final esperado

El estudiante deberá entregar un proyecto BI completo compuesto por:

1. Base de datos limpia y organizada.
2. Flujo ETL documentado.

<!-- Página 2 -->

3. Modelo de datos con relaciones claras.
4. Dashboard ejecutivo en Power BI, R Studio, Tableau, Looker Studio, Excel BI u otra herramienta equivalente.
5. Informe ejecutivo con hallazgos, KPI y recomendaciones.
6. Presentación breve de resultados ante el docente o comité evaluador.

## 5. Desarrollo de la macroactividad

### Fase 1. Comprensión del caso y definición de requisitos

El estudiante identifica el problema de negocio, los usuarios de la solución y las preguntas clave que debe responder el dashboard. Además, define los objetivos del proyecto BI y los indicadores que permitirán evaluar el desempeño comercial.

**Actividades mínimas:**

- Describir el problema de la empresa.
- Identificar usuarios del dashboard.
- Definir objetivos del proyecto BI.
- Formular preguntas de negocio.
- Seleccionar KPI principales.

**KPI sugeridos:**

- Ventas totales.
- Cumplimiento de metas.
- Ticket promedio.
- Productos más vendidos.
- Margen de utilidad.
- Ventas por zona.
- Ventas por vendedor.
- Variación mensual de ventas.

### Fase 2. Preparación de datos y proceso ETL

El estudiante recopila, revisa, limpia y transforma los datos necesarios para el análisis. Esta fase debe evidenciar el tratamiento técnico de los datos antes de su visualización.

**Actividades mínimas:**

- Importar datos desde una o varias fuentes.
- Eliminar duplicados.
- Corregir datos vacíos o inconsistentes.
- Estandarizar nombres, fechas, códigos y categorías.
- Crear columnas calculadas cuando sea necesario.

<!-- Página 3 -->

- Documentar el flujo ETL aplicado.

**Fuentes posibles:**

- Archivo de ventas.
- Archivo de clientes.
- Archivo de productos.
- Archivo de vendedores.
- Archivo de metas comerciales.
- Archivo de zonas o canales.

### Fase 3. Diseño del modelo de datos

El estudiante estructura el modelo de datos para facilitar el análisis. Debe establecer relaciones entre tablas y construir una base lógica que permita generar indicadores confiables.

**Actividades mínimas:**

- Definir tablas de hechos y dimensiones.
- Relacionar ventas con productos, clientes, vendedores, fechas y metas.
- Validar la coherencia de las relaciones.
- Crear medidas o cálculos de análisis.
- Verificar que los indicadores respondan a las preguntas de negocio.

**Modelo sugerido:**

- Tabla de hechos: ventas.
- Dimensiones: productos, clientes, vendedores, zonas, calendario y metas.

### Fase 4. Construcción del dashboard

El estudiante diseña un dashboard ejecutivo, claro, funcional e interactivo. El tablero debe permitir interpretar el desempeño comercial y apoyar la toma de decisiones.

**Elementos mínimos del dashboard:**

- Tarjetas KPI.
- Gráfico de ventas por mes.
- Ranking de productos.
- Cumplimiento de metas por vendedor.
- Ventas por zona o canal.
- Segmentadores por fecha, producto, vendedor y zona.
- Semáforo o alerta visual de cumplimiento.
- Visualización comparativa entre ventas reales y metas.

<!-- Página 4 -->

**Criterios visuales:**

- Claridad.
- Orden.
- Coherencia gráfica.
- Lectura rápida.
- Uso adecuado de títulos.
- No saturación visual.
- Pertinencia de los gráficos.

### Fase 5. Informe ejecutivo

El estudiante redacta un informe breve, técnico y ejecutivo. El documento debe explicar el problema, la metodología aplicada, los principales hallazgos y las recomendaciones de mejora.

**Estructura sugerida del informe:**

1. Título del proyecto.
2. Descripción del problema.
3. Objetivo del proyecto BI.
4. Fuentes de datos utilizadas.
5. Proceso ETL aplicado.
6. Modelo de datos construido.
7. KPI analizados.
8. Principales hallazgos.
9. Recomendaciones.
10. Conclusión ejecutiva.

### Fase 6. Presentación de resultados

El estudiante presenta la solución BI en una exposición breve. Debe explicar el problema, mostrar el dashboard, interpretar los indicadores y justificar las recomendaciones propuestas.

**Aspectos esperados:**

- Dominio técnico del proyecto.
- Explicación clara de los KPI.
- Interpretación de hallazgos.
- Uso correcto del dashboard.
- Propuestas de mejora basadas en datos.
- Comunicación ejecutiva.
