# Evidencias de la Macroactividad

Las evidencias visuales se organizan por origen para evitar confundir los resultados generados por el análisis con las capturas de la aplicación.

- `graficos_r`: once gráficos creados automáticamente por `scripts/macro_bi.R`.
- `capturas_shiny`: cinco capturas actuales seleccionadas para documentar el dashboard final. La pestaña de conclusiones permanece disponible en Shiny, pero su captura no se conserva porque las conclusiones se desarrollan en el informe ejecutivo.

Al volver a ejecutar el script, los gráficos se actualizan únicamente dentro de `graficos_r`. Las capturas de Shiny se actualizan después de ejecutar y revisar visualmente la aplicación.
